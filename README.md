---



🧠 1. WEBSITE TYPE (Exact Classification)



Type: Single-page personal brand funnel



Scroll: Linear vertical scroll (no multi-page navigation focus)



Structure: Conversion-first landing page disguised as portfolio





👉 This is NOT a traditional website with pages like:



Blog



Resources



Complex navigation





Instead: 👉 Everything is designed to push user → BOOK CALL





---



🧱 2. EXACT PAGE FLOW (Real Order)



Here is the actual structure in order:



1. Navbar (sticky)

2. Hero Section

3. About Section

4. Credibility / Authority

5. Services / What I Do

6. Content / Media

7. Final CTA

8. Footer



No extra sections like:



Pricing tables



Blog



FAQs (minimal or none)





👉 This is intentional → reduces distraction





---



🔝 3. NAVBAR (Precise Breakdown)



Elements:



Left: Name/logo (text, no heavy logo graphic)



Right: Single CTA button





Behavior:



Sticky (fixed position)



On scroll:



Background becomes solid dark



Slight shadow appears







CSS-like structure:



position: fixed;

top: 0;

width: 100%;

z-index: high;

backdrop-filter: blur(8px);



👉 No multiple menu links

👉 No dropdowns

👉 Only action-focused design

🎯 4. HERO SECTION (Pixel-Level Breakdown)



Layout Grid:



Container: ~1200px

Grid: 2 columns (or centered stack on mobile)





---



Elements (Exact Order):



1. Headline (H1)



Large (approx 56–64px)



Bold weight



Short sentence (NOT paragraph)





👉 Purpose: Authority statement





---



2. Subheadline



Smaller (18–20px)



Grey tone (not pure white)





👉 Purpose: Clarify value





---



3. CTA Button



Rounded corners (~8–12px)



Padding: large (14px–20px)



Color: white or gold





👉 Hover:



Slight scale (1.03)



Background shift







---



4. Background



Either:



Dark gradient OR



Real estate image/video with overlay







Overlay:



background: rgba(0,0,0,0.6);





---



Micro Details:



Line height tight (1.1–1.2)



Letter spacing slightly reduced



Max width: ~600px
